# Simple AI Agent

This project is a simple AI agent that can perform three tasks: searching, calculating, and listing files.

## How to Run

1.  Run the agent:
    ```bash
    python agent.py
    ```

2.  Enter a command at the prompt. The available commands are:
    *   `search <query>`
    *   `calculate <expression>`
    *   `list_files [path]`

3.  To exit the agent, type `exit`.
